# ADR 0001 — Tickets are stored as files in the repo

- **Status:** accepted (same decision as `sdlab` ADR 0001)
- **Date:** 2026-11-16

## Context

Development is done with agent sessions and a human owner as reviewer. Every session must know exactly what its task is. Cloud agents do not always have a valid GitHub API token, but they can always read the repo contents.

## Decision

Tickets are Markdown files with YAML frontmatter in `backlog/tickets/`. `backlog/BOARD.md` is generated by `scripts/board.py`. Ticket status changes are committed in the same PR as the work itself. Ticket ids follow the master plan: `S-001`, sub-tickets `S-001a`.
