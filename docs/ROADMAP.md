# Roadmap

`sdsim` carries **Phase 2 (simulation system)** and the lab-facing part of **Phase 3 (application)** of the SD Lab project. Phase 1 (materials) lives in `../sdlab`.

| Phase | Where | Status |
| --- | --- | --- |
| 1. Materials | `sdlab` | Curriculum, sources, content format and the first pilot lesson are done; Unit 0 content production is next |
| 2. Simulation system | `sdsim` | Planned; see [PLAN.md](PLAN.md) |
| 3. Application | `sdsim` (labs) and a later plan for lessons, quiz, progress | Not planned in detail yet |

Direction from the owner (sdlab ADR 0007, 2026-11-16): the owner is the only beta tester for now; Unit 0 ships first; the next goal is a working quiz and lab. The simulator milestones S0-S5 are in the STUD Simulator Master Plan and [PLAN.md](PLAN.md).
